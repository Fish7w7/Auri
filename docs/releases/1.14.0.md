# Auri 1.14 — Integração com navegador 2.0

Esta versão aproxima o navegador da biblioteca local sem abrir mão de confirmação explícita e integridade dos dados.

## Novidades

- **Contexto de leitura no navegador:** a Auri Extension 0.3.0 mostra progresso, status, relação da página atual e uma opção segura para continuar a leitura quando houver uma fonte vinculada.
- **Reconhecimento entre fontes:** obras equivalentes podem ser reconhecidas por IDs externos e aliases exatos, mantendo fontes novas como não vinculadas até sua confirmação.
- **Mesclar obras:** escolha a obra mantida, revise a prévia, decida conflitos e una fontes, aliases, histórico, coleções e metadados com backup automático anterior.

## Melhorias

- Atualizações de progresso pelo navegador guardam a última página lida somente quando a URL e a fonte foram verificadas.
- A Biblioteca oferece mesclagem rápida para exatamente duas obras selecionadas.
- Os filtros aplicam alterações imediatamente, informam os critérios ativos e fecham por Esc, botão ou clique fora.
- O pacote Embedded 0.3.0 e a instalação do Native Host de produção validam hash, identidade, permissões e origins autorizadas.

## Correções

- Sufixo SEO conhecido não é salvo como alias novo durante uma mesclagem; palavras legítimas em títulos continuam preservadas.
- Fontes lógicas equivalentes são consolidadas sem descartar a URL de leitura mais recente ou a preferência escolhida.
- IDs externos diferentes no mesmo provedor impedem a mesclagem antes que dados sejam alterados.

O Auri 1.14.0 mantém schema **3**, suporte a schemas **1-3**, `@auri/protocol` **0.2.0**, `PROTOCOL_VERSION = 1` e Native Host PROD `app.auri.native_host`.

Disponível para **Windows x64**.
