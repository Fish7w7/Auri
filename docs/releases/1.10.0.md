# Auri 1.10.0 - Auri no navegador

A principal novidade desta versão é a integração com a Auri Extension.

- Reconheça obras diretamente da página.
- Abra obras no Desktop.
- Adicione novas obras e fontes.
- Atualize o progresso de leitura.
- Preencha a capa automaticamente no cadastro.
- Evite obras e fontes duplicadas.
- Use comunicação local e autenticada pelo Native Host.
- Receba o Native Host configurado automaticamente pelo instalador.
- Continue usando o Auri normalmente sem a extensão.

A versão também preserva as melhorias de funcionamento offline, resiliência de rede, updater, bandeja do sistema e inicialização introduzidas na linha 1.9.

`Auri-Setup-1.10.0-x64.exe`  
Windows x64
